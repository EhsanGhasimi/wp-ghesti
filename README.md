# wp-ghesti

افزونه افزایش درصد اسنپ‌پی و باکس اقساط پویا. سورس در wp-snapppay/ است. نسخه جاری ۱.۳.۲؛ شورت‌کدهای [webinew_installments] و [wp_snapppay_notice]، ویرایشگر دیداری/HTML و واتس‌اپ 09361810430. محاسبه هر قسط: (قیمت نمایشی + هزینه درصدی روی قیمت بدون مالیات) / ۴.

توسعه‌دهنده: احسان قسیمی - Ehsan Ghasimi | مجموعه: وبینیو

راهنمای افزونه و معرفی مجموعه در wp-snapppay/readme.txt است؛ شرح تاریخی پروژه قبلی در HISTORY-FA.md نگهداری شده و مسیرهای قدیمی آن مرجع ساخت فعلی نیستند.

## توسعه و ساخت

این پوشه ریشه پروژه است. فایل‌های افزونه را در زیرپوشه هم‌نام ویرایش کنید. دستور PowerShell از ریشه: ./scripts/build.ps1

ZIP نصب و کنترل SHA256 در dist/ ساخته می‌شوند. فایل‌های راهنمای توسعه و تست وارد ZIP افزونه نمی‌شوند. شناسه پوشه‌های وردپرس تغییر نکرده است.

## بررسی

دستور: node tests/licensing-runner.mjs

تست یکپارچه به سورس هر دو پروژه هم‌سطح نیاز دارد؛ جزئیات نصب ابزارها و تنظیم مسیرها در tests/README.md است. ابزارهای تست شامل Node dependencies و sodium_compat در .validation همین پروژه کپی و با SHA256 بررسی شده‌اند؛ اجرای تست به پوشه قدیمی وابسته نیست. تست یکپارچه همچنان عمداً سورس هر دو پروژه هم‌سطح را بررسی می‌کند.

## انتشار

ZIP خام wp-snapppay باید پیش از نصب مشتری در پنل مرکزی «آماده‌سازی ZIP» شود. بسته آماده‌شده شامل تنظیم اعتماد عمومی سرور است؛ کلید خصوصی یا کلید لایسنس را در مخزن ذخیره نکنید.

SDK مرجع در پروژه webinew-license-manager/sdk است. برای همگام‌سازی عمدی SDK محصول، در پروژه wp-snapppay دستور ./scripts/build.ps1 -SyncSdk را اجرا کنید. ساخت عادی فایل SDK محصول را بازنویسی نمی‌کند.



## فعال‌سازی اضطراری آفلاین
قابلیت کد امضاشده WNR1 اضافه شده است. شاه‌کلید با محصول *، سایت * و مدت صفر برای همه محصولات این صادرکننده و SDK جدید معتبر است. با کد اضطراری، هیچ بررسی شبکه‌ای انجام نمی‌شود و لغو آنلاین هم ممکن نیست. کد محدود به دامنه/محصول/مدت نیز قابل صدور است. پیش از خرابی سرور کد و پشتیبان امضا را خارج از هاست نگه دارید. راهنمای کامل در پروژه لایسنس: docs/recovery-FA.md. سایر افزونه‌های مصرف‌کننده نیز باید SDK جدید را دریافت کنند. وابستگی‌های عادی افزونه همچنان الزامی‌اند.


## کد ثابت مالک (WNM)
کد ثابت مالک اکنون بدون اتصال به سرور، بدون صدور لایسنس برای سایت و بدون آماده‌سازی ZIP قابل استفاده است؛ تنها محصول باید SDK جدید داشته باشد. اسنپ‌پی ۱.۳.۱ از این روش پشتیبانی می‌کند. کد در فایل خصوصی .secrets/webinew-master-key.txt پروژه لایسنس به مالک تحویل داده می‌شود و در ZIPها نیست. برای سایر محصولات، SDK جدید را یک‌بار توزیع کنید. محدودیت نسخه‌های قدیمی، محرمانگی کد، ذخیره محلی و روش استفاده در docs/master-key-FA.md پروژه لایسنس توضیح داده شده‌اند. راهنمای صدور قبلی WNR1 فقط برای قابلیت اختیاری کد امضاشده است و برای استفاده از کد ثابت WNM نیازی به آن نیست.



## تغییر نام به wp-ghesti — نسخه ۱.۳.۲
نام افزونه در وردپرس و نام بسته نصب اکنون wp-ghesti است. فایل قابل نصب dist/wp-ghesti.zip است. برای حفظ سازگاری نصب‌های قبلی، پوشه و فایل اصلی، شناسه محصول لایسنس wp-snapppay، تنظیمات و شورت‌کدهای قبلی حفظ شده‌اند. در پنل مرکزی همچنان محصول wp-snapppay را انتخاب کنید. بسته قدیمی dist/wp-snapppay.zip مربوط به نسخه پیشین است.
